# Pasta local e projeto na interface

A pasta central é `repo-root:.`. Sua existência não cria automaticamente um projeto na barra lateral.

A ferramenta oficial listou `Projetos` como projeto local e `VISÃO COMPUTACIONAL` como projeto ChatGPT. Não listou este caminho como projeto local individual. Não há operação exposta para cadastrar uma pasta nova; a inspeção CUA do aplicativo Codex foi bloqueada por segurança antes de observar a interface. Nenhum projeto, conversa ou configuração foi alterado.

Passo manual: no aplicativo, crie/edite um projeto local e associe esta pasta. Para projetos existentes, a documentação oficial descreve **Edit project → Add folder** e **Make primary** para definir a pasta inicial. O rótulo de criação na versão instalada não foi observado. [Documentação oficial](https://learn.chatgpt.com/docs/projects).

O [parecer de capacidade](../00-indice/registros/codex-project.md) preserva essa verificação. Não há cadastro confirmado ou novo remoto GitLab por esta entrega.
