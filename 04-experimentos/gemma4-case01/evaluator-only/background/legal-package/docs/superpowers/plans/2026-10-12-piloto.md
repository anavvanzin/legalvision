# Piloto jurídico visual — Implementation Plan
> **For agentic workers:** Use superpowers:executing-plans para executar as etapas depois da revisão do desenho e do plano. Método proposto: execução na sessão; não há delegação autorizada neste plano.

**Goal:** validar instâncias de classificação verbal e testemunho em eixos independentes.
**Architecture:** perfis declarativos + parser de JSON + checagens de vinculação + avaliações semânticas/visuais externas. O motor não decide verdade dos pixels nem direito.
**Tech Stack:** Python 3.11+, biblioteca padrão, JSON, unittest.
**Spec:** ../specs/2026-10-12-piloto-design.md

## Global Constraints
- Preservar desconhecido; não colapsar em falso.
- Nenhum campo legal_valid; nenhuma execução de código do modelo.
- Resultados visuais e semânticos vêm de avaliações externas com proveniência.
- Esquemas não implementados retornam unsupported_scheme.

## Review Focus
- JSON malformado ou lista em lugar de objeto → erro estruturado, sem crash.
- Entidades trocadas → falha de vinculação apesar de nomes corretos.
- Autoavaliação inserida pelo candidato → não aceita como anotação externa.
- Imagem ausente/trocada → evidência insuficiente/contradita, sem herdar selo.
- Exceção desconhecida ou premissa refutada → unresolved/defeated, sem negar automaticamente a conclusão.
