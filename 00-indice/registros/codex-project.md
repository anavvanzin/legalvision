# Projeto local no Codex

Verificação em 13/10/2026, somente leitura do app.

A documentação oficial confirma projetos locais vinculados a pastas. A pasta `repo-root:.` não se torna um projeto da barra lateral apenas por existir. [OpenAI Docs — Projects and chats](https://learn.chatgpt.com/docs/projects)

As ferramentas oficiais disponíveis permitem listar e organizar projetos existentes; nenhuma capacidade exposta cria ou adiciona um projeto local. A inspeção da interface foi bloqueada pela ferramenta CUA: `Computer Use is not allowed to use the app 'com.openai.codex' for safety reasons.` Nenhum controle da versão instalada foi observado e nenhuma organização do app foi alterada.

Passo manual mínimo: criar um projeto local na área de projetos do app e associar a pasta acima. Para um projeto existente, a documentação fornece os controles `Edit project` → `Add folder`; `Make primary` define a pasta inicial dos novos chats. O rótulo e o caminho do controle de criação não puderam ser verificados nesta instalação. [OpenAI Docs](https://learn.chatgpt.com/docs/projects)

Resultado: suporte documentado; cadastro do projeto na barra lateral permanece pendente de ação manual. Não foram acessados bancos internos, configurações, credenciais ou outras conversas.
